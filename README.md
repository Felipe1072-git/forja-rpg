# Forja RPG

Regras da mesa de Forja RPG: uma versão simplificada de D&D, no estilo do Shadowdark, com classes prontas e criação livre de habilidades.

Site: https://felipe1072-git.github.io/forja-rpg/

O conteúdo fica em `docs/` (Markdown) e é publicado com MkDocs Material pelo GitHub Actions a cada push na `main`.

```bash
pip install mkdocs-material
mkdocs serve
```
